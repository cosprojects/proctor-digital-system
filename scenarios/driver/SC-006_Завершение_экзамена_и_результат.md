# SC-006

## 1. Общая информация

- Код сценария: SC-006
- Роль: Driver
- Название: Завершение Exam и результат
- Lifecycle States Attempt: **Completed**, **AI Processing**, **Review Required**, **Decision Made**, **Published**, **Archived**

---

## 2. Цель сценария

Предоставить Driver понятный предварительный результат аттестации, объяснить дальнейшие действия и корректно завершить пользовательский сценарий.

Экран результата завершает взаимодействие пользователя с системой прокторинга. Внутренние процессы проверки, принятия решения и публикации результата выполняются системой независимо и не требуют участия Driver.

Driver видит понятный статус обработки результата; внутренние Review / Decision процессы не превращаются в пользовательский интерфейс Driver.

Количество зафиксированных предупреждений (Alerts) не является само по себе итоговым результатом аттестации.

## 6. Основной сценарий

1. Пользователь завершает экзамен.
2. Система сохраняет ответы и завершает Attempt.
3. Система получает результат экзамена из LMS.
4. Система отображает экран предварительного результата аттестации.
5. Пользователь видит:
   - количество набранных баллов;
   - количество зафиксированных предупреждений;
   - понятный статус обработки результата;
   - статус аттестации.
6. Если аттестация считается успешно пройденной:
   - отображается сообщение об успешном прохождении;
   - отображается уведомление о дополнительной проверке видеозаписи;
   - пользователь информируется, что проверка может занять время (конкретный срок не определён).

## 7. Альтернативные сценарии

### Аттестация успешно завершена

Система отображает:

- количество набранных баллов;
- количество предупреждений;
- сообщение:

> Аттестация успешно завершена.

Дополнительно отображается информационный баннер:

> Проводится дополнительная проверка видеозаписи. При обнаружении существенных нарушений результат аттестации может быть аннулирован.

Конкретный срок проверки не определён.

---

### Аттестация не пройдена

Причины могут включать:

- недостаточное количество баллов;
- невозможность подтвердить прохождение согласно регламенту.

Система отображает:

- результат экзамена;
- причины отказа;
- предложение пройти аттестацию повторно (повторная запись / Retake).

Пользователь может перейти к повторной записи на аттестацию.

---

### Результат временно недоступен

Если результат невозможно получить сразу:

- система сообщает, что результат обрабатывается;
- рекомендует повторить попытку позже;
- пользователь может закрыть экран.

---

### Техническая ошибка

Если произошла техническая ошибка:

- система сообщает о невозможности показать результат;
- рекомендует повторить попытку позже;
- предлагает обратиться в службу поддержки при необходимости.

## 11. Функциональные элементы

### Для зоны «Результат аттестации»

- Статус аттестации.
- Итоговое сообщение.
- Иконка результата.

### Для зоны «Баллы»

- Итоговый балл.
- Минимальный проходной балл.
- Признак успешного прохождения.

### Для зоны «Предупреждения»

- Количество предупреждений.
- Краткое пояснение.
- Отметка, что количество предупреждений не является итоговым результатом аттестации.

### Для зоны «Следующие действия»

При успешной аттестации:

- дополнительных действий не требуется.

При неуспешной:

- возможность повторного прохождения аттестации (повторная запись / Retake).

### Для зоны «Информационный баннер»

- информация о дополнительной проверке видеозаписи;
- статус проверки (конкретный срок не определён);
- возможность аннулирования результата при обнаружении существенных нарушений.

### Для зоны «Основное действие»

При успешной аттестации:

- Завершить.

При неуспешной:

- Пройти аттестацию повторно (Retake).

## 13. Edge Cases

- результат еще обрабатывается;
- невозможно получить результат;
- временно отсутствует соединение;
- пользователь закрыл приложение;
- произошла техническая ошибка отображения результата.

Во всех случаях система должна сохранить Attempt, обеспечить возможность повторного получения результата и предоставить пользователю понятное объяснение дальнейших действий.

---

## 14. Критерии успеха

Сценарий считается завершенным, если:

- пользователь получил понятный предварительный результат аттестации;
- отображено количество набранных баллов;
- отображено количество предупреждений;
- при успешной аттестации показана информация о дополнительной проверке видеозаписи;
- при неуспешной аттестации предложена возможность пройти аттестацию повторно (Retake);
- пользователь понимает дальнейшие действия;
- пользовательский сценарий завершен.
