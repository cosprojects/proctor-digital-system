# SC-003

## 1. Общая информация

- Код сценария: SC-003
- Роль: Driver
- Название: Подготовка и проверка условий прохождения Exam
- Lifecycle State Attempt: **Environment Checking**

---

## 2. Цель сценария

Подготовить пользователя к Identity Verification, автоматически проверить готовность устройства и условий проведения (Environment Checking). Перевести Attempt в переход к Identity Verification (SC-004). Environment Checking готовит пользователя только к Identity Verification и не запускает сам Exam.

Attempt — жизненный цикл прокторинга вокруг будущей экзаменации в LMS; Environment Checking не является Identity Verification и не изменяет Exam в LMS.

Не содержит Identity Verification, загрузку фотографии из КИС АРТ и CTA начала Exam.

## 4. Preconditions

- пользователь завершил SC-001;
- Attempt находится в состоянии **Draft** (переход к **Environment Checking**);
- пользователь открыл подготовку к прохождению;
- Exam Session доступна.

---

## 5. Trigger

Пользователь открывает этап Environment Checking.

---

## 6. Основной сценарий

1. Система переводит Attempt в состояние **Environment Checking**.
2. Система запрашивает доступ к камере, если разрешение еще не предоставлено.
3. После получения доступа система одновременно выполняет:
   - проверку доступности и работоспособности камеры;
   - проверку интернет-соединения;
   - оценку освещения;
   - определение наличия и положения лица в кадре.
4. Пользователь получает собственное изображение с камеры.
5. Система отображает актуальный статус каждой проверки.
6. Система в режиме реального времени сообщает, как устранить обнаруженные проблемы:
   - улучшить освещение;
   - полностью открыть лицо;
   - приблизиться к камере или отдалиться от нее;
   - изменить положение устройства;
   - восстановить интернет-соединение;
   - предоставить доступ к камере.
7. После изменения условий система автоматически повторяет затронутые проверки.
8. Система рассчитывает общую готовность только после успешного завершения всех обязательных проверок окружения.
9. Система сообщает о готовности к Identity Verification.
10. Пользователь может перейти в SC-004.
11. Система передает результаты Environment Checking в SC-004 без вынесения решения о личности.

---

## 7. Альтернативные сценарии

### Камера недоступна или перестала работать

- система сообщает, что видеопоток не получен;
- объясняет возможную причину;
- предлагает проверить камеру и повторить проверку;
- переход к следующему этапу остается недоступен.

### Доступ к камере запрещен или отозван

- система сообщает, что без разрешения проверка невозможна;
- предлагает открыть системные настройки и предоставить доступ;
- после возврата автоматически проверяет разрешение повторно.

### Недостаточное освещение

- система фиксирует недостаточную видимость лица;
- рекомендует изменить источник света или положение пользователя;
- повторяет оценку в реальном времени.

### Лицо не обнаружено или видно частично

- система сообщает конкретную причину;
- рекомендует изменить расстояние, ракурс или убрать препятствие;
- повторяет проверку положения лица.

### Потеря интернет-соединения

- система приостанавливает зависимые проверки;
- сохраняет уже полученные локальные результаты, если они остаются актуальными;
- сообщает о необходимости восстановить соединение;
- после восстановления повторяет сетевую и зависимые проверки.

### Фотография из КИС АРТ

Не загружается в SC-003. Загрузка эталонной фотографии Driver выполняется в SC-004 (Identity Verification).

### Проверка не завершилась по технической причине

- система называет незавершенную проверку;
- предлагает повторить только ее;
- при повторном сбое сообщает о невозможности продолжить и доступном канале поддержки.

Во всех случаях система объясняет, что произошло, почему продолжение ограничено и что необходимо сделать дальше.

## 11. Функциональные элементы

Для зоны "Контекст сценария"

- Идентификатор и название сценария.
- Статус доступности Exam Session.
- Описание цели и состава Environment Checking.

Для зоны "Предпросмотр камеры"

- Получение видеопотока с выбранной камеры.
- Отображение пользователю текущего изображения с камеры.
- Контроль непрерывности видеопотока.
- Признак наличия лица в кадре.
- Признак полноты видимости лица.
- Оценка расстояния и ракурса пользователя.

Для зоны "Проверка оборудования"

- Состояние разрешения на использование камеры.
- Статус доступности камеры.
- Статус работоспособности видеопотока.
- Результат проверки интернет-соединения.
- Автоматический повтор проверки после восстановления оборудования или разрешения.

Для зоны "Проверка условий проведения"

- Результат оценки освещения.
- Результат определения положения лица.
- Временная метка и актуальность каждого результата.

Для зоны "Статус готовности"

- Текущий статус каждой обязательной проверки: ожидает, выполняется, успешна или требует действия.
- Агрегированный статус готовности.
- Правило блокировки перехода при незавершенной обязательной проверке.
- Подтверждение успешного завершения всех обязательных проверок.

Для зоны "Подсказки пользователю"

- Определение причины несоответствия условиям.
- Рекомендация по устранению конкретной проблемы.
- Обновление рекомендации при изменении условий.
- Подтверждение, что исправление принято и проверка повторяется.

Для зоны "Основное действие"

- Определение доступности перехода в SC-004 по общей готовности Environment Checking.
- Действие перехода к Identity Verification (SC-004).
- Передача результатов Environment Checking в SC-004.

Для зоны "Ошибки и восстановление"

- Причина ошибки.
- Проверка, которую не удалось завершить.
- Последствие ошибки для продолжения сценария.
- Рекомендованное действие восстановления.
- Повтор только затронутой проверки.
- Состояние восстановления соединения, камеры или разрешения.
- Канал поддержки при повторном техническом сбое.

## 13. Edge Cases

- потеря соединения во время параллельных проверок;
- камера перестала работать после успешной первичной проверки;
- пользователь свернул приложение во время проверки;
- пользователь отозвал разрешение на камеру;
- освещение изменилось после успешной проверки;
- лицо вышло из кадра после успешной проверки;
- фотография из КИС АРТ не относится к SC-003 (загружается в SC-004);
- результат одной из проверок устарел до завершения остальных;
- пользователь повторно открыл этап подготовки;
- приложение было выгружено системой во время проверки;
- несколько проверок требуют исправления одновременно.

При изменении критического условия ранее успешный результат соответствующей проверки аннулируется и проверка выполняется повторно.

---

## 14. Критерии успеха

Сценарий считается завершенным если:

- все обязательные проверки окружения успешно завершены и их результаты актуальны;
- пользователь понимает текущий статус каждой проверки;
- пользователь получил понятные рекомендации по устранению обнаруженных проблем;
- система подтвердила готовность к Identity Verification;
- результаты Environment Checking готовы к передаче в SC-004;
- пользователь может перейти в SC-004.
