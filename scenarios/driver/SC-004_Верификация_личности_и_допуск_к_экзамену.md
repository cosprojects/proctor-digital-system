# SC-004

## 1. Общая информация

- Код сценария: SC-004
- Роль: Driver
- Название: Identity Verification и допуск к Exam
- Lifecycle State Attempt: **Identity Verification** → **Ready**

---

## 2. Цель сценария

Выполнить Identity Verification, подтвердить личность Driver и перевести Attempt в состояние **Ready**.

Модель Identity Verification:

- Identity Verification выполняет наша система;
- данные личности и эталонная фотография всегда поступают из КИС АРТ.

Включает загрузку эталонной фотографии Driver из КИС АРТ (владелец данных: КИС АРТ).

## 4. Preconditions

- завершен SC-003;
- Attempt находится в состоянии **Environment Checking** (переход к **Identity Verification**);
- все обязательные проверки Environment Checking выполнены успешно;
- результаты SC-003 остаются актуальными;
- камера активна;
- лицо Driver находится в кадре.

---

## 5. Trigger

После успешного завершения Environment Checking система переводит Attempt в **Identity Verification** и автоматически запускает процедуру верификации личности.

---

## 6. Основной сценарий

1. Система переводит Attempt в состояние **Identity Verification**.
2. Система загружает эталонную фотографию Driver из КИС АРТ.
3. Система получает актуальный кадр лица Driver.
4. Наша система автоматически выполняет сравнение лица с фотографией из КИС АРТ без необходимости дополнительных действий пользователя, кроме нахождения в кадре.
5. Система фиксирует начало процедуры и текущий статус проверки.
6. Пользователь получает актуальный статус Identity Verification без необходимости выполнять дополнительные действия.
7. Система оценивает результат сравнения по установленным правилам допуска.
8. При достаточном уровне совпадения система подтверждает личность Driver.
9. Система переводит Attempt в состояние **Ready**.
10. Пользователь получает однозначный результат успешной Identity Verification и допуска без дополнительного экрана подтверждения.
11. Пользователь сразу переходит к Exam.
12. Система передает подтверждённый допуск и контекст Attempt в SC-005.

---

## 7. Альтернативные сценарии

### Не удалось получить фотографию из КИС АРТ

- система не начинает сравнение без эталонной фотографии;
- сообщает причину невозможности проверки;
- повторяет запрос к КИС АРТ, если повторная попытка допускается;
- не принимает положительное решение о допуске без результата верификации.

### Личность не подтверждена

- система фиксирует отрицательный или неопределенный результат сравнения;
- сообщает, что личность не подтверждена;
- не переводит Attempt в **Ready**;
- предлагает повторную проверку только в пределах установленной политики.

### Недостаточное качество изображения

- система не интерпретирует низкое качество как несовпадение личности;
- сообщает причину невозможности достоверного сравнения;
- предлагает восстановить необходимые условия;
- после восстановления получает новый кадр и повторяет проверку.

### Лицо исчезло из кадра

- система приостанавливает или отменяет текущую операцию сравнения;
- сообщает о необходимости вернуть лицо в кадр;
- после восстановления условия начинает проверку с актуальным изображением.

### Проверка завершилась технической ошибкой

- система отделяет технический сбой от отрицательного результата верификации;
- сообщает о технической причине;
- предлагает повторить проверку, если сервис доступен;
- при исчерпании повторных попыток сообщает о невозможности продолжить и доступном канале поддержки.

Во всех альтернативных сценариях система сообщает причину, последствия для допуска и доступное следующее действие.

## 9. User Flow

Старт  
↓  
Перевод Attempt в **Identity Verification**  
↓  
Загрузка фотографии Driver из КИС АРТ  
↓  
Получение актуального кадра  
↓  
Автоматическое сравнение лица  
↓  
Оценка результата  
↓  
Личность подтверждена?  
↓

Нет → Объяснение результата → Повторная проверка допустима?  

- Да → Восстановление условий → Новое сравнение.  
- Нет → Attempt не переведена в **Ready** → Завершение сценария.

Да  
↓  
Attempt переведена в **Ready**  
↓  
Переход к Exam (SC-005)

## 11. Функциональные элементы

Для зоны "Контекст сценария"

- Идентификатор и название сценария.
- Идентификатор Attempt.
- Lifecycle State: **Identity Verification**.
- Актуальность результатов SC-003.
- Наличие обязательных данных для запуска верификации.

Для зоны "Статус верификации"

- Состояние процедуры: ожидает запуска, выполняется, завершена или требует действия.
- Фиксация времени начала и завершения проверки.
- Признак актуальности используемого кадра.
- Признак доступности сервиса сравнения.
- Обновление статуса при повторной проверке.

Для зоны "Проверка личности"

- Получение актуального кадра лица.
- Получение эталонной фотографии из КИС АРТ.
- Проверка пригодности входных изображений для сравнения.
- Автоматическое сравнение лица с эталонной фотографией без необходимости действий пользователя, кроме нахождения в кадре.
- Оценка достоверности результата по установленным правилам.
- Отделение недостаточного качества изображения от несовпадения личности.

Для зоны "Результат проверки"

- Результат верификации: подтверждено, не подтверждено или невозможно определить.
- Причина неопределенного или отрицательного результата.
- Фиксация результата в контексте Attempt.
- Переход Attempt в **Ready** при успешной верификации.
- Понятное последствие результата для продолжения сценария.

Для зоны "Допуск к Exam"

- Применение правил допуска к результату Identity Verification.
- Перевод Attempt в **Ready** при положительном результате.
- Защита от перехода в SC-005 без состояния **Ready**.
- Передача контекста Attempt в SC-005.

Для зоны "Ошибки и повторная проверка"

- Классификация причины: качество данных, отсутствие фотографии, несоответствие условий или технический сбой.
- Проверка доступности повторной проверки по установленной политике.
- Счетчик и статус повторных проверок.
- Получение нового актуального кадра перед повторным сравнением.
- Повторный запрос фотографии или обращение к сервису КИС АРТ.
- Сохранение различия между технической ошибкой и неподтвержденной личностью.
- Рекомендованное действие восстановления.
- Канал поддержки при невозможности завершить проверку.

## 13. Edge Cases

- фотография пользователя отсутствует в КИС АРТ;
- фотография повреждена, устарела или непригодна для сравнения;
- сервис КИС АРТ временно недоступен;
- камера отключилась во время сравнения;
- пользователь отозвал разрешение на использование камеры;
- лицо покинуло кадр во время проверки;
- качество изображения ухудшилось после запуска сравнения;
- интернет-соединение потеряно во время передачи или обработки данных;
- повторная проверка завершилась ошибкой;
- исчерпан лимит повторных попыток;
- получен неопределенный результат сравнения;
- результаты SC-003 утратили актуальность до завершения верификации;
- пользователь свернул или закрыл приложение во время проверки;
- пользователь повторно открыл сценарий после принятия решения;
- результат получен после завершения допустимого времени ожидания.

Технический сбой или недостаточное качество данных не должны автоматически классифицироваться как несовпадение личности.

---

## 14. Критерии успеха

Сценарий считается завершенным если:

- личность Driver подтверждена на основании актуальных и пригодных данных;
- Attempt переведена в состояние **Ready**;
- пользователь понимает результат Identity Verification и его последствия;
- пользователь может перейти к Exam;
- контекст Attempt передан в SC-005.
