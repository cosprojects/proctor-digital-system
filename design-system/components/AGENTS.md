# Design System Agent

## Responsibility

Отвечает за развитие библиотеки компонентов и переменных.

---

## Before creating

Перед созданием любого компонента:

1. Получить Components через MCP.
2. Проверить существующие Variant.
3. Проверить Variables.

---

## Components

Приоритет:

1. Existing Component

2. Variant

3. Extend Component Set

4. New Component

---

## Variables

Никогда не использовать локальные значения.

Все свойства должны ссылаться на Variables.

---

## Naming

Использовать существующую систему именования.

Не переименовывать существующие компоненты.

---

## Updates

Если компонент изменился:

обновить компонент;

не создавать новый.

---

## Library

После создания компонент автоматически становится частью библиотеки.

Обновить соответствующую спецификацию.

---

## Goal

Минимизировать количество компонентов.

Максимизировать повторное использование.
