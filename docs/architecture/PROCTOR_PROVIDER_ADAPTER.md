# Proctor Provider Adapter

## Назначение

Наша система не реализует собственную платформу видеоконференцсвязи.

Используется внешний поставщик (ProctorEdu, Examus), который обеспечивает прохождение экзамена и предоставляет данные завершённой proctoring-сессии для последующего asynchronous Review:

- видеоматериалы (запись экрана, основная камера, дополнительная камера при наличии, аудио);
- события провайдерской AI-обработки.

В дальнейшем список может расширяться.

Recording (запись, хранение и обработка видео) принадлежит нашей платформе.

Provider не является владельцем Recording.

---

## Архитектурный принцип

Наша система следует принципу Provider Agnostic и не зависит от конкретного поставщика.

Все взаимодействие осуществляется через слой адаптера.

Внутренние сценарии, компоненты интерфейса и бизнес-логика работают только с унифицированной моделью данных.

---

## Provider Adapter

Adapter отвечает за:

- создание экзаменационной комнаты;
- получение статусов подключения;
- получение статусов участников;
- получение AI событий;
- получение видеопотока для Recording нашей системы;
- завершение экзаменационной комнаты.

Adapter не передаёт владение Recording Provider.

В asynchronous-модели Adapter получает данные завершённой proctoring-сессии (события провайдерской AI-обработки, видеоматериалы) и передаёт их в автоматическую обработку (AI Processing) для последующего Review.

Конкретный API-контракт взаимодействия с Provider определяется при проектировании интеграции.

## Normalized Events

Внутренние события системы:

- FaceDetected
- FaceLost
- SecondPersonDetected
- BackgroundNoise
- CameraDisabled
- ConnectionLost
- IdentityVerified
- IdentityRejected
- WarningCreated
- ViolationConfirmed
- ExamFinished

События используют унифицированные названия и не зависят от специфики API конкретного поставщика.

---

## Responsibility

Provider отвечает только за:

- видеоконференцию;
- поток видео;
- поток аудио;
- встроенные AI события.

Provider не владеет:

- Recording;
- Exam;
- Decision;
- Authorization.

Наша система отвечает за:

- Authorization (роли и права; Authentication — SUDIR);
- расписание;
- экзаменационные сессии;
- Identity Verification;
- Recording (запись, хранение, обработка);
- сценарии;
- управление участниками и прокторами;
- AI Orchestration и Review;
- принятие Decision;
- отчеты;
- аналитику;
- audit.
