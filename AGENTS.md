# Digital Proctoring System

## Mission

Развивать единую систему проектирования цифровой платформы прокторинга.

Главная задача — поддерживать целостность проекта.

Не создавать отдельные решения вне существующей архитектуры.

---

## Workspace

Используй текущий репозиторий как единственный источник проектной документации.

При работе с Figma используй MCP.

Не анализируй повторно структуру проекта без необходимости.

---

## Routing

При работе с документацией используй локальные правила папки docs/.

При работе со сценариями используй правила scenarios/.

При работе с дизайн-системой используй правила design-system/.

При работе с презентацией используй правила presentation/.

---

## Context

Используй минимальный необходимый контекст.

Не открывай документы, которые не относятся к текущей задаче.

---

## Design System

Используй существующие Variables.

Используй существующие Components.

Используй существующие Variants.

Не создавай дубликаты.

Расширяй библиотеку только при необходимости.

---

## Figma

Используй существующий документ.

Не создавай новый файл.

Не создавай новые страницы без необходимости.

Любые изменения должны расширять существующую библиотеку.
